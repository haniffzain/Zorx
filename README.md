Zorx is an independent project exploring a focused, desktop-class experience for
Android. The project is currently under active private development.

## Public updates

This repository is the official public landing page for Zorx. Product announcements,
release information and public downloads will be published here when they are ready.

Source code, engineering documentation, development history and internal project
tracking are maintained in a separate private repository.
